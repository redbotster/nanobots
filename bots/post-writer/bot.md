# post-writer

Turn one idea into platform-ready posts for X, LinkedIn, and Threads in my voice.

`openclaw` harness, one `ai.generate` call. Drafts only — this bot never posts anything; that's `post-publisher`'s job, behind its own approval gate.

`voice_sample` (an optional file input) is accepted but not read into the prompt yet — the same disclosed gap `draft-replies`' own `voice_sample` input has.
